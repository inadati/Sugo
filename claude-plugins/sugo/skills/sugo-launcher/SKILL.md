# sugo-launcher

ユーザーが「sugo」と入力したら、このスキルを使ってハーネスを選択・起動する。

## 手順

### 1. ハーネス一覧を取得

`sugo_status()`（harness_id なし）を呼び出して全ハーネスのサマリーを取得する。

### 2. 表形式で一覧を表示

以下の形式で Markdown テーブルを出力する：

```
利用可能なハーネス：

| # | ハーネス名 | 説明 |
|---|-----------|------|
| 1 | しりとりデモ | AIがしりとりを実演するデモ |
| 2 | ...        | ...  |

番号を入力してください（例：「1」）
```

- `description` が null または空の場合は「—」と表示する
- `has_draft: true` のハーネスには ⚠ マークを付ける（起動不可）

### 3. 番号入力を待機

ユーザーが番号（例: `1`）を入力したら、対応するハーネスを起動する。

- `has_draft: true` のハーネスが選ばれた場合：「このハーネスにはドラフトセルがあるため起動できません。`/sugo:sugo-draft-resolve` で解決してください。」と伝える
- それ以外は `sugo_start(harness_id=..., project_path=<カレントディレクトリ>)` を呼び出す
- `project_path` は必ず「このスキルが実行されているNipperタブの実際のカレントディレクトリ」を使うこと。固定パスをハードコードしてはならない（タブごとにプロジェクトパスが異なるため、誤ったパスを指定すると別タブに誤配信される）

### 4. 起動後は待機

`sugo_start` の戻り値には `run_id` しか含まれない。
プロンプトとエッジは Nipper が次のターンに注入する。
**このターン内では絶対にハーネス内容を処理しない。**
